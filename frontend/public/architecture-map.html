2. Ядро коммерции (Core Commerce Services)
📦
Inventory Service
Склад, блокировки FOR UPDATE, брони
Postgres: stocks, reservations Redis DB 2 Celery: expire 5s
GET /api/v1/stocks/{product_id}
Остаток
POST /stocks/{id}/reserve
Бронь (FOR UPDATE)
POST /stocks/{id}/commit
Списание в продажу
POST /stocks/{id}/release
Возврат стока
События Outbox / Очереди:
outbox ➔ inventory.InventoryReserved
outbox ➔ inventory.InventoryCommitted
outbox ➔ inventory.ReservationReleased
🛒
Orders Service
Заказы, чекауты, промокоды
Postgres: orders, promocodes Celery: expire 5s
POST /api/v1/orders
Создать заказ
POST /api/v1/orders/batch
Чекаут корзины
GET /api/v1/orders/{order_id}
Детали заказа
POST /promocodes/validate
Скидка
События Outbox / Очереди:
outbox ➔ orders.OrderCreated
outbox ➔ orders.OrderCancelled
💳
Payments Service
Оплата заказов, mock/real шлюз
Postgres: payments
POST /api/v1/payments
Создать счет
POST /payments/{id}/confirm
Оплата успешна
POST /payments/{id}/fail
Ошибка оплаты
События Outbox / Очереди:
outbox ➔ payments.PaymentSucceeded
outbox ➔ payments.PaymentFailed

Catalog Service

Поиск и фильтры
GET /api/v1/products/{slug}

POST /api/v1/products/batch
Список по ID
GET /api/v1/categories
